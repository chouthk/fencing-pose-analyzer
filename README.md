# 🤺 劍擊動作 AI 骨骼分析系統 (Fencing AI Pose Analyzer MVP)

這是一套基於 **Python + Streamlit + MediaPipe Pose** 的輕量級劍擊動作分析系統。無需昂貴的 GPU，即可在一般電腦或筆記本上快速流暢運行。

## 🌟 核心功能
1. **影片上傳**：支持上傳 MP4 / MOV 格式的弓步（Lunge）或刺擊（Attack）影片。
2. **骨骼關節即時角度計算**：
   - **持劍手伸展度 (Arm Extension)**：計算 肩-肘-腕 夾角，評估刺擊時手臂是否充分伸直。
   - **前膝彎曲度 (Knee Angle)**：計算 髖-膝-踝 夾角，評估弓步下沉深度。
3. **即時畫面標註**：動態將角度數值與 33 個身體關鍵點骨架連線繪製在影片影格上。
4. **AI 動作診斷報告**：
   - 自動捕捉最大手臂伸展角與弓步前膝最低夾角。
   - 給出專業的生物力學反饋（例如手臂伸展是否充分、前膝是否下沉過度或深度不足）。
5. **數據時序曲線**：即時繪製手臂伸展度隨時間變化的趨勢圖。
6. **影片下載**：允許下載已完成 AI 標註的分析影片。

## 🚀 快速開始

### 1. 安裝環境依賴
請確保你的電腦已安裝 Python 3.8 - 3.11（推薦）或 3.12。在終端機中運行以下命令安裝依賴：

```bash
pip install -r requirements.txt
```

*(如果遇到 MediaPipe 安裝問題，請確保 Python 版本與 MediaPipe 官方支援相符，或使用 Python 3.11 虛擬環境)*

### 2. 啟動應用
在專案根目錄下，於終端機執行：

```bash
streamlit run app.py
```

瀏覽器會自動打開 `http://localhost:8501` 展示分析系統介面。
